# LFNY en order — privacy policy

Rendered page: **https://agtamts.github.io/lfny-en-order-policy/**

Hosts the privacy policy page required by the Chrome Web Store listing. The extension
source lives in a separate private repository; `index.html` here mirrors
`docs/privacy.html` there and is published by `node tools/publish-privacy.mjs`.

Unofficial fan tool. Not affiliated with NBC or Saturday Night Live.
