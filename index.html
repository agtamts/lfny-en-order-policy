Privacy policy — SNL en order

Last updated: 2026-11-15 · Chrome extension “SNL en order”

SNL en order does not collect, transmit, sell or share any personal data.

What the extension reads

  • The current YouTube page: the playlist title and the list of clips in the playlist you opened. This is read in the page itself and never sent anywhere except back to the YouTube page, to play the next clip.
  • The matching episode page on https://snl.fandom.com, requested to obtain that episode's broadcast order. Only the episode page name is sent; no identifiers, no user data, and the request is made without credentials.

What is stored

Stored locally in your browser via chrome.storage.local, never uploaded:

  • your manual order for an episode, if you reorder clips;
  • the clip you last watched in each episode, so the panel can offer “resume”;
  • cached wiki responses (7 days) so the wiki is not requested on every page load.

Removing the extension deletes all of it.

What is not done

  • No analytics, telemetry, crash reporting or advertising.
  • No cookies or accounts.
  • No remote code: all JavaScript ships inside the extension package.

Contact

Use the developer contact email shown on the Chrome Web Store listing for “SNL en order”.
